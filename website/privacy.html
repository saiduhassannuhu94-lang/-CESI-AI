CESI AI Privacy

CESI is designed around user control. Microphone, contacts, calls, location and notification features are requested only when the corresponding feature needs them.

Current test build

Conversation history used by the current test build is stored locally on the device. Future cloud AI features will require explicit disclosure, data handling rules and consent before production release.

Third-party services

Web search, speech engines and future AI providers may process information according to their own policies. CESI will document production integrations before public release.
